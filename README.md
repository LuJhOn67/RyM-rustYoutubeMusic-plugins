# RyM plugins

The plugin store of [RyM](https://github.com/LuJhOn67/RyM). The apps read `plugins.json` from this
repository: every plugin listed here shows up in the app's plugin store, and a higher `version`
shows up as an update for people who installed it.

| Plugin | What it does |
|---|---|
| `video` 1.0.0 | YouTube video player and universal downloader: watch a song's music video, download videos, download from YouTube or any site yt-dlp supports. Without it RyM is an audio-only music player. |

## متجر إضافات RyM

البرنامج يقرا `plugins.json` من هنا: كل إضافة مكتوبة بيه تطلع بمتجر الإضافات داخل البرنامج، ومن يزيد رقم `version` يطلع تحديث للي منصّبها.

- **`video`** 1.0.0: مشغّل فيديو يوتيوب والمحمّل الشامل. تشوف فيديو الأغنية، تحمّل فيديوهات، وتحمّل من يوتيوب أو أي موقع يدعمه yt-dlp. بدونها يبقى RyM مشغّل موسيقى صوت بس.
